# FUTURE_DS_02 - Customer Retention & Churn Analysis

## Overview
Analysis of Telco customer data to identify churn patterns, 
retention drivers and customer lifetime trends using Power BI.

## Key Insights
- 26.54% overall churn rate — 1,869 customers lost
- Month-to-month contracts have the highest churn
- Electronic check payment method leads in churn
- Fiber optic customers churn the most
- New customers churn more in first 12 months

## Tools Used
- Power BI Desktop
- Power Query (Data Cleaning)

## Recommendations
1. Convert month-to-month customers to annual contracts
2. Incentivize automatic payment methods
3. Improve Fiber optic service quality
4. Target new customers with retention offers
5. Introduce loyalty rewards for long term customers
